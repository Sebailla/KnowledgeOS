# Plugin Foundation Frozen Baseline

**Package:** `@knowledgeos/plugin`  
**Version:** `1.0.0`  
**Status:** Frozen  

Stable surfaces:

- Plugin Engine.
- Plugin Manager.
- Plugin Registry.
- Plugin Manifest and Descriptor.
- Plugin Capability and Permission.
- Dependency Resolver.
- Compatibility validator.
- Plugin Provider and Module.
- In-memory reference provider.

Breaking changes require an ADR and a major package version.
