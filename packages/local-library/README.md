# @knowledgeos/local-library

Offline-first Local Library domain and application services.

## Part 1 includes

- local publication records;
- acquisition state;
- verified local commit;
- offline access;
- deterministic Local Manifest;
- integrity inspection;
- explicit eviction;
- pin protection;
- in-memory repository for integration tests.

The Local Library never changes canonical Master Publication content. Personal Knowledge remains a separate subsystem.
