# Kernel Frozen Baseline

**Package:** `@knowledgeos/kernel`  
**Version:** `1.0.0`  
**Status:** Frozen  

The Kernel public API is considered stable after Sprint 001.3.

## Stable surfaces

- Engine lifecycle and dependency ordering.
- Kernel states and typed lifecycle errors.
- Capability registry.
- Command Bus, Query Bus and Event Bus.
- Execution Context and cancellation.
- Middleware composition.
- Retry abstraction.
- Idempotency coordination.
- Unit of Work boundary.
- Monotonic ID generation.

Breaking changes require an ADR and a major package version.
