# OCR Foundation Frozen Baseline

**Package:** `@knowledgeos/ocr`  
**Version:** `1.0.0`  
**Status:** Frozen  

Stable surfaces:

- OCR Engine.
- OCR Pipeline.
- OCR Provider and Session.
- OCR Source, Document, Page and Text Block.
- Region and language contracts.
- Apple Vision, Tesseract and Remote provider contracts.
- In-memory reference provider.

Breaking changes require an ADR and a major package version.
