# Knowledge Graph Foundation Frozen Baseline

**Package:** `@knowledgeos/knowledge-graph`  
**Version:** `1.0.0`  
**Status:** Frozen  

Stable surfaces:

- Knowledge Graph Engine.
- Graph Provider and Store.
- Graph Node, Edge and Path.
- Neighbor and Traverse queries.
- In-memory reference provider.
- Search projection adapter.

Breaking changes require an ADR and a major package version.
