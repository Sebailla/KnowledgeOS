# Export Foundation Frozen Baseline

**Package:** `@knowledgeos/export`  
**Version:** `1.0.0`  
**Status:** Frozen  

Stable surfaces:

- Export Engine.
- Export Pipeline.
- Export Provider and Writer.
- Export Transformer.
- Export Source, Artifact and Result.
- Markdown and HTML base exporters.
- PDF and EPUB provider contracts.

Breaking changes require an ADR and a major package version.
