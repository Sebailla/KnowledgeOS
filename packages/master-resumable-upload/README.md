# @knowledgeos/master-resumable-upload

Durable resumable-upload sessions for large authoritative publications.

## Includes

- durable filesystem session state;
- out-of-order chunk upload;
- per-chunk SHA-256 verification;
- interruption and resume;
- progress reporting;
- deterministic assembly;
- final registration through Master Registration Workflow;
- cancellation and abandoned-session cleanup.
