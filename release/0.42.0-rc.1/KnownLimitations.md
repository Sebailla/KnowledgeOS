# Known Limitations

- Apple signing, notarization, TestFlight and App Store submission require external Apple credentials and must run on macOS with Xcode.
- Mobile AI uses remote/server providers; heavyweight local mobile inference is not part of RC1.
- PDF and EPUB generation are foundation implementations and require further format-conformance testing before public release.
- Share Extension and background-task behavior require validation on physical Apple devices.
- Closed beta telemetry is not enabled.
