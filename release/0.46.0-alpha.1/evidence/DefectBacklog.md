# Defect Backlog

## Severity

- **P0:** data loss, security breach or system-wide outage.
- **P1:** critical workflow blocked without acceptable workaround.
- **P2:** important defect with a workaround.
- **P3:** minor defect, usability issue or cosmetic regression.

## Release gate

Promotion from `alpha` requires zero unresolved P0 and P1 defects. Every corrected defect requires a regression test or explicit evidence when automation is not possible.
