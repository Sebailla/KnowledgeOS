# AGENTS

This file applies to `01-Implementation/07-LocalReadingFoundation`.

- The module implements opening and reading publications already available in a Local Library.
- It SHALL NOT implement source discovery, acquisition, annotations, search, synchronization, AI or plugins.
- Reading SHALL remain fully available offline for locally available publications.
- UDM owns semantic reading order; DPM owns source-faithful presentation.
- UI SHALL use Platform contracts and SHALL NOT access persistence directly.
- Reading position is Personal Knowledge and SHALL never be written to the Master Library.
