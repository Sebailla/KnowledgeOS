# AGENTS

This file applies to `01-Implementation/08-ImportAndAcquisition`.

- Local scanning SHALL be limited to user-authorized locations.
- Import SHALL preserve original source bytes and provenance.
- Acquisition SHALL be explicit, resumable and idempotent.
- Acquisition SHALL NOT be implemented as Personal Knowledge synchronization.
- Local Library membership is device-specific.
- Duplicate detection provides evidence; it SHALL NOT silently collapse distinct sources.
- Canonical processing begins only after successful validation and local registration.
