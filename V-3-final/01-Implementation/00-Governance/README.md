# 00-Governance README

## Scope

This folder contains the governance artifacts that apply across the KnowledgeOS V-3 implementation plan: the implementation strategy, the module development lifecycle, and the Definition of Done. These documents set the rules and shared expectations that all modules and contributors must follow.

The files inside this section are drafts to be filled in during planning. Use them as the authoritative reference for how the project organizes work, sequences delivery, and decides when an item is complete. Update them as the project evolves so they remain a faithful description of the current governance model.
