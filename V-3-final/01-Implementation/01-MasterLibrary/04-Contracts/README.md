# 04-Contracts README

## Scope

This folder contains the external contract artifacts for the KnowledgeOS V-3 Master Library: the server API surface, the authentication model, and the catalog and acquisition contracts. These documents define what clients can rely on and what the server promises, independently of how either side is implemented.

- [ServerAPI](./ServerAPI.md)

## How to use this section

The files inside this section are drafts to be filled in during planning. Treat each contract as a public commitment — once published, breaking changes require a documented migration. Update them as the design converges so they always match what the server actually offers.
