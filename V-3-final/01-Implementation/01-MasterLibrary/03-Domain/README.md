# 03-Domain README

## Scope

This folder contains the domain model artifacts for the KnowledgeOS V-3 Master Library: the overall domain model, the entities, the value objects, the entity states, and the domain errors. These documents describe the business concepts and rules independently of any technical implementation.

## How to use this section

The files inside this section are drafts to be filled in during planning. Start with `DomainModel.md` for the high-level model, then drill into entities, value objects, state transitions, and errors. Keep these documents free of technology choices so they remain portable across implementations.
