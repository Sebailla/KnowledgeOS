# 02-TechnicalDesign README

## Scope

This folder holds the technical design artifacts for the KnowledgeOS V-3 Master Library: the overall technical architecture, the technology stack choices, the repository structure, and the deployment model. These documents describe *how* the module will be built, distinct from *what* it must do.

## Index

- [TechnicalArchitecture](./TechnicalArchitecture.md)
- [TechnologyStack](./TechnologyStack.md)
- [RepositoryStructure](./RepositoryStructure.md)
- [DeploymentModel](./DeploymentModel.md)

## How to use this section

The files inside this section are drafts to be filled in during planning. Read `TechnicalArchitecture.md` for the high-level design, then drill down into the stack, repository layout, and deployment model. Update them as decisions are made so they always reflect the currently agreed design.
