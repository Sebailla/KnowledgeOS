
# Activity – Import Workflow

## Objetivo

Describir el flujo completo de importación de documentos.

---

## Flujo

1. Seleccionar documento.
2. Detectar formato.
3. Determinar si requiere OCR.
4. Extraer contenido.
5. Analizar estructura.
6. Construir UDM.
7. Validar resultado.
8. Incorporar a la Library.
