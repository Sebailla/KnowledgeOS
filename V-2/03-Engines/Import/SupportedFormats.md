
# Supported Formats

Versión: 1.0
Estado: Draft

---

# Objetivo

Definir los formatos que la plataforma puede importar.

## Soportados en la versión 1.0

- PDF
- Markdown
- Plain Text
- HTML

## Planificados

- DOCX
- EPUB
- RTF
- ODT

## Futuros

- Imágenes (OCR)
- Audio
- Video
- Correo electrónico

---

# Reglas

- Cada formato posee un parser dedicado.
- Todos generan el mismo UDM.
