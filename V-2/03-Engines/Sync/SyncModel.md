# Sync Model

Versión: 1.0
Estado: Draft

---

# Propósito

Definir los conceptos utilizados durante una sincronización.

---

# Componentes

- Workspace Snapshot
- Change Set
- Sync Session

---

# Reglas

- Toda sincronización opera sobre un Workspace.
- Toda sincronización posee un identificador único.
- Todo cambio pertenece a un Change Set.
