# Propósito

Definir los renderizadores disponibles.

## Renderizadores

- Document Renderer
- Block Renderer
- Inline Renderer
- Table Renderer
- Image Renderer
- Code Renderer
- Math Renderer

---

# Reglas

- Cada renderer conoce un único tipo de elemento.
- Los renderers son independientes entre sí.
- Todos consumen el UDM.
