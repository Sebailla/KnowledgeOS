# 1. Purpose

This directory contains the minimum UML view set required to clarify important dynamic and lifecycle semantics of KnowledgeOS Architecture V3.

The UML views complement the normative architecture and C4 views. They do not replace the normative documents.

# 2. Active Views

* `Runtime-Lifecycle.puml`
* `Background-Job-State-Machine.puml`
* `Synchronization-Flow.puml`
* `Import-Pipeline.puml`

# 3. Selection Principle

Only UML views with lasting architectural value are included.

The current set focuses on:

* Runtime lifecycle;
* durable Background Job lifecycle;
* Synchronization execution flow;
* Import execution pipeline.

# 4. Authority

If a UML view conflicts with normative architecture, the normative architecture and accepted ADRs prevail.

# 5. Status

**Approved**

This directory defines the initial official UML baseline for KnowledgeOS Architecture V3.
