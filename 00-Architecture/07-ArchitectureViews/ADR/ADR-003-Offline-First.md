# ADR-003 — Offline First

**Project:** KnowledgeOS  
**Section:** Architecture Views / ADR  
**Version:** 4.0  
**Status:** Accepted  
**Author:** KnowledgeOS Team  

---

## 1. Context

Apple clients must remain useful without NAS or Internet connectivity.

## 2. Decision

Local Libraries and local Platform capabilities SHALL support full offline reading, annotations, search and processing for locally available content. Remote work is deferred or degraded explicitly.

## 3. Consequences

Requires local persistence, resumable workflows and conflict-safe synchronization.

## 4. Supersession

None

## 5. Status

**Accepted**
