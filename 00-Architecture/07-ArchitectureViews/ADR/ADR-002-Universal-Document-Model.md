# ADR-002 — Universal Document Model

**Project:** KnowledgeOS  
**Section:** Architecture Views / ADR  
**Version:** 4.0  
**Status:** Accepted  
**Author:** KnowledgeOS Team  

---

## 1. Context

Source formats mix storage, semantics and presentation.

## 2. Decision

Adopt UDM as the canonical semantic representation of documentary knowledge, independent of source format, rendering and persistence. DPM remains separate for presentation.

## 3. Consequences

Enables consistent processing, search and AI; requires canonicalization, identity and validation.

## 4. Supersession

None

## 5. Status

**Accepted**
