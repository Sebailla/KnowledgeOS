## Purpose

The C4 views describe KnowledgeOS at system, container, component and deployment levels.

## Diagram Set

- `C4-L1-SystemContext.puml`: users and external systems.
- `C4-L2-Containers.puml`: Apple clients, NAS server, Master Library, Local Libraries and iCloud.
- `C4-L3-PlatformEngines.puml`: Platform Engine boundaries.
- `C4-Deployment-Native-NAS-Providers.puml`: native clients, NAS containers and external providers.

## Rules

Diagrams MUST use consistent aliases, explicit relationships and architecture vocabulary. Personal synchronization and publication acquisition MUST remain separate in every view.
