## Purpose

The UML diagrams describe critical runtime and lifecycle behavior.

## Diagram Set

- publication acquisition;
- local import pipeline;
- Personal Knowledge synchronization;
- runtime lifecycle;
- background job state machine.

## Rules

Behavioral diagrams SHALL preserve Domain lifecycle states, Engine ownership, idempotency, offline-first operation and explicit failure paths.
