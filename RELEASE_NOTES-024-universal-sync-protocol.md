# Sprint 024 — Universal Synchronization Protocol

## Directorio de instalación

Descomprimir en la raíz de `KnowledgeOS/`.

## Cambios

- USP 1.0 operations, batches, envelopes, cursors, ACK and checkpoints.
- Deterministic serialization and checksums.
- Protocol validation and version compatibility.
- Operation idempotency and out-of-order detection.
- Server endpoints for envelopes, pull and checkpoints.
- Swift DTOs for cross-platform protocol interoperability.
