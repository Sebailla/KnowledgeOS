# Feedback and Defect Guide

## Severity

- **P0:** data loss, security breach or complete service outage.
- **P1:** critical workflow blocked without a safe workaround.
- **P2:** important defect with a workaround.
- **P3:** minor defect, usability issue or enhancement request.

## Required fields

- version and build;
- platform and OS version;
- severity;
- steps to reproduce;
- expected and actual behavior;
- frequency;
- sanitized diagnostic package;
- regression status when fixed.
