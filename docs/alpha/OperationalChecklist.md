# Alpha Operational Checklist

## Before a field cycle

- Confirm evaluator consent.
- Confirm authorized devices and installed build.
- Confirm NAS backup freshness.
- Confirm PostgreSQL and authoritative file volumes are separate.
- Confirm no P0 or P1 defect is open.
- Confirm diagnostic collection remains opt-in.

## During the cycle

- Record build and channel.
- Run smoke tests after updates.
- Collect only sanitized metrics.
- Track sync conflicts and queue growth.
- Preserve diagnostic correlation identifiers.

## After the cycle

- Export evidence.
- Review failed checks.
- Update benchmark history and defect backlog.
- Revoke access for inactive evaluators.
