# Closed Alpha Evaluator Guide

The Alpha validates reliability and usability; it is not a production release.

## Critical flows

- import and open a document;
- work offline and reconnect;
- create bookmarks and annotations;
- search and inspect graph relations;
- synchronize between devices;
- export and share content;
- restart clients and NAS services without losing data.

## Reporting

Report one defect per issue. Include the affected version, platform, reproduction steps, expected result, actual result and a sanitized diagnostic package. Never attach private documents, tokens or credentials.
