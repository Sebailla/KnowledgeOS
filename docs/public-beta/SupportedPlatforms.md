# Supported Platforms

| Platform | Minimum | Status |
|---|---:|---|
| macOS | 14 | Public beta |
| iOS | 17 | Public beta through TestFlight-ready workflow |
| iPadOS | 17 | Public beta through TestFlight-ready workflow |
| NAS server | Docker-compatible Linux, amd64/arm64 | Public beta deployment |
| PostgreSQL | 17 | Supported authoritative metadata store |

Apple distribution still requires valid signing, provisioning, notarization and TestFlight credentials.
