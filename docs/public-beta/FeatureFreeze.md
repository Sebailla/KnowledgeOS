# Feature Freeze

KnowledgeOS 0.49.0-beta.2 is functionally frozen. New engines, public capabilities, storage models, synchronization semantics, import formats, export formats, AI providers, and platform targets are prohibited during the freeze.

Allowed changes are limited to defect correction, security remediation, compatibility preservation, accessibility correction, documentation, packaging, observability, performance stabilization, and approved migration work.

Every exception requires an owner, rationale, affected contracts, risk, regression evidence, rollback plan, and release-governance approval.
