# Public Beta Guide

KnowledgeOS 0.49.0-beta.2 is a controlled public beta intended for evaluation, not production-critical use. Evaluators should keep independent backups, review known issues, install only signed distribution artifacts, and attach sanitized diagnostics to defect reports.

Core workflows under evaluation are library management, offline reading, synchronization, annotations, search, graph exploration, import, export, and cross-device continuity.
