# Public Beta Release Checklist

- [ ] Feature-freeze validation passes.
- [ ] No open P0/P1 defects.
- [ ] Regression and E2E suites pass.
- [ ] Migrations and rollback are validated.
- [ ] Checksums and SBOM are generated.
- [ ] Diagnostics are sanitized.
- [ ] Supported platforms and known issues are current.
- [ ] Distribution artifacts are signed where required.
- [ ] Release approval is recorded.
