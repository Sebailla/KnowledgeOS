# Beta Installation Guide

KnowledgeOS 0.48.0-beta.1 is a private beta. Install only on approved devices and NAS environments with verified backups.

1. Back up PostgreSQL and authoritative files.
2. Validate the release manifest and checksums.
3. Deploy NAS services before clients.
4. Install macOS, iOS and iPadOS builds from the approved beta channel.
5. Run `scripts/beta/validate-beta-installation.sh`.
