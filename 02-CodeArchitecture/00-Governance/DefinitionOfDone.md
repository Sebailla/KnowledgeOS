# Code Architecture Definition of Done

**Project:** KnowledgeOS  
**Section:** Code Architecture / Governance  
**Document:** DefinitionOfDone  
**Version:** 5.0  
**Status:** Release Candidate  
**Author:** KnowledgeOS Team  

---

A package or application is complete when its public API, dependencies, tests, build, generated artifacts, migration impact, observability and V4 traceability are documented and validated. Forbidden imports, unversioned contracts, handwritten generated types, unresolved placeholders and undocumented persistent changes block completion.
