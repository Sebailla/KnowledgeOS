# Branch and Version Strategy

**Project:** KnowledgeOS  
**Section:** Code Architecture / Repository  
**Document:** BranchAndVersionStrategy  
**Version:** 5.0  
**Status:** Release Candidate  
**Author:** KnowledgeOS Team  

---

Use short-lived branches, protected main, changesets for publishable TypeScript packages and explicit application versions for Apple targets. Contract schema versions are independent of package versions. Breaking wire changes require a major contract version and compatibility plan.
